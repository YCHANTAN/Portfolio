# Personal Portfolio

A modern, high-performance personal portfolio showcasing the intersection of scalable software engineering and environmental science research. Built as a sleek, client-side application using React and TypeScript.

## 🚀 Tech Stack

### Frontend
* **Framework:** React 19 (Vite)
* **Language:** TypeScript
* **Styling:** Tailwind CSS v4, Shadcn UI
* **Animations & UI:** Framer Motion, ReactBits.dev (e.g., Plasma component)
* **Forms:** Web3Forms integration for serverless contact handling.

---

## 📁 Project Structure

```text
portfolio-workspace/
└── frontend/                 # React + TypeScript Client
    ├── src/
    │   ├── components/       # Reusable UI elements and ReactBits animations
    │   ├── sections/         # Page sections (Hero, About, Projects, etc.)
    │   └── App.tsx           # Main application layout
    └── index.css             # Tailwind v4 configuration and custom theme
```
